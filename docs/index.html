You set the permission

Three levels.
Manual or autonomous.

The automatic level is a ceiling. The app never escalates to a level you did not authorize.

01

Safe

Regenerable caches and builds, with Git and processes checked. This is the automatic default.

02

Deep

Adds inactive worktrees and recognized temporary files. Run it now, or authorize it continuously.

03

Emergency

With a specific authorization, it can reach Codex files archived for seven days and regenerable Claude VMs with no open files.

It understands projects, not just folders

Autonomy with a clear boundary.

MAY CLEAN

Inside your permission

  • Regenerable caches, builds, and worktrees
  • At Emergency: archived files with retention, and unused VMs
  • Only after a local check of processes and paths
NEVER TOUCHES

Your real work

  • Documents, Desktop, Downloads, or media libraries
  • Git source, credentials, current sessions, or unselected external disks
  • Existing Trash, Docker data, or active projects

In Settings, choose Trash, deletion of only this app's batch, or an external-drive backup with SHA-256 before anything is removed from the Mac. Older Trash items stay untouched. Read the exact code →
